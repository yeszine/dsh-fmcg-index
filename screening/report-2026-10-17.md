# 快消 / 供应链 / 食品行业 插件与 MCP 筛查报告

- 日期：2026-10-17
- 范围：DSH 插件市场（dshmarketplace.dev，11,363 个仓库，仅取安装检查通过的）、MCP 官方 registry、Smithery
- 原始报告：[screen-2026-10-17.md](screen-2026-10-17.md)
- 复跑：`npm run screen`（脚本 `scripts/screen.mjs`）

## 一、结论

1. **DSH 生态目前没有快消 / 进销存垂直插件。** 60+ 个中英文关键词中，`进销存`、`订单`、`仓储`、`物流`、`配送`、`门店`、`陈列`、`促销`、`回款`、`经销商`、`快消`、`食品`、`冷链`、`保质期`、`采购`、`TMS` 等几乎全部 0 命中；`库存`、`供应链`、`发票`、`对账`、`条码` 只有个位数命中，且包含大量误报。
2. **能用的是「底座」能力**：发票/对账、Excel/Office、主数据清洗、条码、IM（企微/钉钉）、SQL/BI、电商平台。
3. **MCP 侧有少量真正的供应链能力**（库存优化、需求预测、Odoo、物流追踪、标签打印、食品安全、FMCG 数据），但需要封装成 DSH 的配置型 bundle，且多数是海外服务。
4. **建议路线**：先把底座插件收进索引，再自建行业 bundle；两者不冲突。

> 自动打分有同义词噪声（`POS` 命中 position、`ERP` 命中 enterprise 等），以下名单已人工复核，但仍不等于安全审查。

## 四、行业缺口（需要自建 bundle）

筛查结果说明这些能力生态里没有现成的，必须自建：

- 进销存、库存批次效期与临期预警；
- 门店拜访、陈列检查（拍照 + AI 审图）；
- 促销费用申请与核销；
- 经销商回款对账（可先用 `dsh-netcafe` + `dsh-office-tools` 组合）；
- 配送路线与司机协同；
- 业代日报 / 绩效；
- 用友、金蝶、管家婆、旺店通、聚水潭等国内系统对接。
