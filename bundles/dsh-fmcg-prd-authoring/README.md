# @dsh-fmcg/prd-authoring

PRD authoring skill: turn scattered product ideas into reviewable, deliverable requirement documents.

PRD 撰写技能：把零散产品想法整理为可评审、可交付的需求文档。

## 包含技能

- `prd-authoring`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
