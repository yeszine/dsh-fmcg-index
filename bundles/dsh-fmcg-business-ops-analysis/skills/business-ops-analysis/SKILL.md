# 快消经销商经营分析

从经销商的出货、回款、费用与库存数据出发，走完"看懂数据 → 定位问题 → 形成判断 → 输出汇报"的完整链路，产出可直接拿到经营例会上用的结论与行动建议。

## 谁会用到

- 经销商老板 / 总经理：每月要回答"生意好不好、钱赚在哪、风险在哪"
- 销售 / 运营负责人：盯区域、渠道、品类的任务达成与终端动销
- 财务 / 经营分析岗：负责组织月度复盘材料、解释数字为什么波动

## 四项核心能力

| 能力 | 回答什么问题 | 方法详见 |
|---|---|---|
| 趋势与节奏分析 | 生意在变好还是变坏？拐点在哪个月？ | [trend-analysis.md](references/trend-analysis.md) |
| 结构拆解与目标达成 | 收入利润由谁构成？离任务差多少？ | [structure-analysis.md](references/structure-analysis.md) |
| 异常识别与风险分级 | 哪些波动不正常？先处理哪个？ | [anomaly-identification.md](references/anomaly-identification.md) |
| 经营汇报合成 | 怎么把发现讲清楚、推动决策落地？ | [report-synthesis.md](references/report-synthesis.md) |

## 分析主流程

```
步骤 0  数据摸底
        明确：时间粒度（日/周/月）、业务口径（出货 or 实销 or 回款）、
        核心指标清单、可用维度（区域/品类/渠道/客户）、有无任务与预算数据

步骤 1  趋势判断   → 参照 references/trend-analysis.md
        产出：各指标走向 + 同比/环比幅度 + 拐点清单

步骤 2  结构拆解   → 参照 references/structure-analysis.md
        产出：维度占比 + 增量贡献 + 达成率 + 集中度判断

步骤 3  异常排查   → 参照 references/anomaly-identification.md
        产出：分级问题清单（紧急/关注/记录）+ 原因假设

步骤 4  汇报合成   → 参照 references/report-synthesis.md
        产出：经营汇报（结论先行 → 分项论证 → 行动建议）

步骤 5  交付成型
        按用途输出文件：Excel 底稿 / HTML 报告或看板 / PDF 打印版 / 一页纸摘要
```

步骤 1–3 相互独立，可并行推进，最后在步骤 4 汇总并交叉验证。

## 经销商常用指标体系

动手前先核对数据里有哪些字段，再对号入座：

| 类别 | 常见指标 | 解读要点 |
|---|---|---|
| 规模 | 出货额、实销额、回款额、订单数、箱数 | 出货 ≠ 实销，两者背离通常意味着渠道压货 |
| 盈利 | 毛利、毛利率、净利、净利率 | 毛利要用扣除返利与促销折让后的口径看 |
| 费用 | 物流仓储费、人员费、进场费/条码费、促销费 | 费用率上行往往比利润下滑更早出现 |
| 效率 | 库存周转天数、动销 SKU 占比、单店月均产出 | 周转恶化常伴随压货或滞销 |
| 客户 | 活跃网点数、铺货率、CR5 客户占比 | 网点流失是收入下滑的先行信号 |

## 交付物与图表选择

交付形态由读者与场合决定，不绑定任何特定工具，用现有软件生成对应文件即可：

| 场合 | 建议形态 | 说明 |
|---|---|---|
| 月度经营例会 | HTML 页面或演示稿 | 以结论和图表为主，核心判断一屏讲完 |
| 数据留档 / 财务复核 | Excel 工作簿 | 保留明细、透视与可复算公式 |
| 打印呈报 / 存档 | PDF | 版式固定，便于传阅归档 |
| 高层速览 | 一页摘要 | 三段结论 + 三条建议，两分钟读完 |

常见图表的通用选型规则（任何制图工具均适用）：

- 多期走势与同比基线 → 折线图（必要时双轴：金额 + 增速）
- 区域/品类/渠道占比 → 环形图或堆叠柱图
- 任务达成 → 仪表盘或进度条
- 增减量归因 → 瀑布图
- 渠道×品类交叉 → 热力图
- 量价关系 → 柱线组合（柱 = 销量，线 = 均价）

## 口径与置信度纪律

- **口径先行**：每个数字旁边标清统计区间（如"3 月全月""YTD 截至 6/30"）与业务口径（出货/实销/回款）；口径不一致的数字不直接对比。
- **春节错位提醒**：快消品受春节月份漂移影响大，1–2 月的同比环比经常失真，必要时应合并 1–2 月比较或单独加注。
- **置信度三档**：
  - 高：多角度数据互相印证，直接陈述；
  - 中：仅单一来源但数据充分，结论后标注"（中置信度）"；
  - 低：数据不足或仅有孤证，标注"（待核实）"并写明缺什么。
- **双单位呈现**：所有相对变化（%）必须同时给出绝对额，防止"涨了 50% 但只多卖两箱"式的误导。

## 边界与约束

- 数据里找不到依据的判断，明说"无法确认"，不编造数字。
- 能用图表讲清的结论不堆文字；每张图表必须有标题、单位、时间范围。
- 每个分析环节收尾时给出"下一步建议"，不停在罗列现象。
- 严格区分"数据呈现的事实"与"基于事实的推测"，推测部分要给出验证路径。
