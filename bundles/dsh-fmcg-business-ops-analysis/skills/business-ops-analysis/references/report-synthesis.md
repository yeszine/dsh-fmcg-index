# 经营汇报合成（结论 · 复盘 · 建议）

对应能力项：**交叉验证、汇报撰写、行动建议**

## 要回答的问题

把趋势、结构、异常三条线的发现拼成一份汇报：管理层 30 秒能抓住重点，15 分钟能听完论据，并且带着可执行的动作散会。

## 洞察分层：从事实到动作

| 层 | 回答 | 经销商示例 |
|---|---|---|
| 第一层 事实 | 发生了什么 | "8 月出货 610 万，同比 -8%（-53 万）" |
| 第二层 归因 | 为什么发生 | "主因 B 片区客户丙停单，贡献缺口 -95 万，其余片区合计 +42 万" |
| 第三层 预判 | 接下来会怎样 | "若客户丙四季度不恢复，全年任务缺口预计扩大到 180 万" |
| 第四层 对策 | 应该做什么 | "建议两周内完成续约谈判，同时启动该片区替补客户开发" |

自检底线：只停在第一层，等于把报表重新念一遍，那不是分析。合格汇报至少走到第三层，争取给出第四层。

## 合成原则

```
趋势结论 ─┐
结构结论 ─┼→ 互相对照 → 合并同类 → 分层归类 → 转成建议
异常清单 ─┘
```

- 多条线指向同一结论 → 置信度升为"高"，直接陈述
- 只有单一线索 → 保留，但标注"（待核实）"
- 两条线互相打架 → 并列呈现两种解释、各自说明依据，不和稀泥

## 报告骨架

### 1. 一页结论（放在最前）

3–5 句话覆盖：整体好还是坏（对任务、对去年）、最亮眼的一点、最危险的一点、需要老板拍板的事。读者只看这一页也能掌握全局。

### 2. 任务完成总览

| 指标 | 任务 | 实际 | 达成率 | 环比 | 同比 | 评价 |
|---|---|---|---|---|---|---|

评价栏用"提前 / 正常 / 落后"三档，落后项链接到问题清单。

### 3. 趋势章节

核心指标走势图（带去年同期基线），拐点各配一句话解读，给出增速分档结论。

### 4. 结构章节

按本次选定的一两个轴（如"区域"和"渠道"）给出：占比与份额变化、增量归因、集中度提示。

### 5. 问题清单

按影响从大到小排，每条含：事实（第一层）、归因假设（第二层）、不处理的后果（第三层）、量化影响。直接复用异常识别环节的产出。

### 6. 行动建议

每条建议四要素齐全：

```
建议 N [优先级 | 时限]：做什么
  · 依据：由哪条发现触发（指回问题清单编号）
  · 预期：量化收益，如"补上缺口约 20 万/月"
  · 责任：哪个部门 / 岗位牵头
```

建议达到 3 条以上时，附一张节奏表：

| 节奏 | 时间窗 | 动作 | 目标 |
|---|---|---|---|
| 止血 | 7 天内 | 核实停单客户、冻结异常费用 | 止住下滑 |
| 补缺 | 30 天内 | 替补客户开发、费用重谈 | 收窄缺口 |
| 调优 | 90 天内 | 客户结构与品类组合优化 | 改善盈利结构 |

## 交付形态建议

| 读者 / 场合 | 形态 | 取舍 |
|---|---|---|
| 月度经营会 | HTML 页面或演示稿 | 以第 1、2、5、6 节为主，图表说话 |
| 财务复核留档 | Excel 工作簿 | 明细 + 透视 + 可复算公式 |
| 打印呈报存档 | PDF | 全章节，版式固定 |
| 老板路上看 | 一页摘要 | 第 1 节 + 前 3 条建议 |

以上均为通用文件形态，用现有办公软件或任意前端方案生成即可，不依赖特定工具。

## 写作纪律

1. 结论先行，证据随后——"本月落后的主因是 B 片区大客户停单"，而不是先罗列一屏数字
2. 每个变化都量化到绝对额，不写"有所下降"这类空话
3. 归因分清内外：执行问题（业务员、铺货、费用）与市场因素（竞品、季节、厂家政策）分开说
4. 对比基准说出口：对任务、对上月、对去年，还是对行业，写清楚
5. 数据只能证明相关，因果留一句"需业务侧确认"
6. 洞察层级走到第三层再收尾

- [ ] 图表有标题、单位、时间范围？
