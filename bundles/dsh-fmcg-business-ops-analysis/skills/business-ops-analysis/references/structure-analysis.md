# 结构拆解与目标达成

对应能力项：**维度拆解、贡献归因、目标完成度、集中度风险**

## 要回答的问题

总盘子的收入和利润是谁贡献的——哪些区域、哪些品类、哪些渠道在赚钱？和年度任务比，缺口卡在哪个局部？

## 经销商的三个标准拆解轴

| 轴 | 常见取值 | 关注重点 |
|---|---|---|
| 区域 | 片区 / 城市 / 线路 | 增量从哪个片区来，哪个片区在拖后腿 |
| 品类 / 品牌 / SKU | 代理的品牌组合 | 利润集中在谁身上，滞销 SKU 占比多少 |
| 渠道 | KA 大卖场、CVS 便利店、流通批发、电商、特通团购 | 各渠道费率差异大，盈利结构悬殊 |

一次只沿一两个轴拆到底；区域×品类×渠道×月份的四维组合只会把人淹没。

## 方法工具箱

| 方法 | 用途 | 要点 |
|---|---|---|
| 占比分解 | 看清构成 | 份额与份额变化（pp）同时给 |
| 增量归因 | 解释总量变化 | 各单元对总增减额的贡献 |
| 交叉透视 | 找局部机会 | 如"区域×渠道"看哪里铺货不足 |
| 达成率核算 | 对照任务 | 拆到最小责任单元 |
| 集中度评估 | 提示依赖风险 | CR3 / CR5 或头部占比 |

### 增量归因怎么算

```
总增减额 = 各单元增减额之和
某单元贡献度 = 该单元增减额 ÷ 总增减额
```

贡献度可以超过 100%、也可以是负数——这恰恰是它的价值：

> 例：全公司 6 月同比多卖 90 万，其中 A 片区 +130 万（贡献 144%），B 片区 -40 万（贡献 -44%）。结论：增长全靠 A 片区扛，B 片区在失血。

## 目标完成度

### 常用算式

```
达成率     = 实际 ÷ 任务
进度健康度 = 达成率 ÷ 时间进度（已过时间占比）
  > 1.0 提前；0.85–1.0 正常；< 0.85 亮红灯
缺口       = 任务 − 实际
追赶要求   = 缺口 ÷ 剩余月数，再对照近三月月均，得出"每月要多卖多少"
全年预估   = YTD 实际 + 剩余月数 × 近三月月均（基准情形）
           乐观 / 悲观两档分别用历史最好、最差月均替换
```

### 输出要求

- 各责任单元达成率从低到高排，短板放在最前面
- 达成率不足六成的单元：重点标注 + 单独写一段归因
- 用进度健康度区分"真落后"和"节奏问题"（例如中秋品类本来就要三季度才发力）
- 全年预估给乐观 / 基准 / 悲观三档，不要只给一个点

## 执行步骤

1. 扫数据，列出所有可分组列（区域、品类、品牌、渠道、客户、业务员……）
2. 按"对当下决策最有用"的原则选 1–2 个轴
3. 分组汇总，算份额、排名、累计占比
4. 做增量归因，找出拉动项与拖累项
5. 有任务数则逐单元算达成率与进度健康度
6. 与上期结构对比，份额变动超过 3 个百分点的单元单独点评

## 判断纪律

- 份额和绝对额一起报，防止"占比第一但总额很小"的误读
- 头部两名合计占比超七成时，主动提示集中度风险（如"收入七成压在同一个 KA 系统"）
- 没有任务数时，用去年同期或近半年均值做参照，并注明这是替代基准
- 多表关联对不上 key 时，停下来告知用户，不硬拼
- 毛利拆解务必用"扣除返利与促销折让后"的口径，否则结论会虚高

## 经销商场景示例句式

- "华东片区贡献出货 47%（份额同比 -4pp），当月总增量 -80 万中它贡献 -65 万，是主要拖累"
- "CR3 客户占收入 72%，且前三名为同一 KA 系统，单一渠道依赖度偏高"
- "品类甲 YTD 达成率 55%，进度健康度 0.73，按近三月月均推算全年仅达 82%，剩余每月需多卖 28% 才能达标"
- "流通渠道毛利率 18%，KA 渠道扣除进场与促销费用后仅 6%——收入增长主要靠 KA，意味着利润正在被稀释"
