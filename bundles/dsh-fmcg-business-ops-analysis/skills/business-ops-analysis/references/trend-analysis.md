# 趋势与节奏分析（同比 / 环比 / 拐点）

对应能力项：**趋势判断、同比环比、拐点识别**

## 要回答的问题

经销商的核心指标（出货额、毛利、回款、活跃网点数）随时间在往哪走——持续向上、掉头向下、原地横盘，还是季节性起伏？如果发生了转向，转折点出现在哪个月？

## 先统一时间口径

| 口径 | 含义 | 经销商典型用法 |
|---|---|---|
| MoM 环比 | 本期 vs 上一期 | 看短期动能、费用异动 |
| YoY 同比 | 本期 vs 去年同期 | 剔除季节后看真实增长 |
| MTD | 月初至今 | 月中盯月度任务进度 |
| YTD | 年初至今 | 年度合同任务完成度 |
| 滚动 3 月均值 | 最近三个月平均 | 平抑单月噪声看走向 |

动笔前必须和用户敲定口径。同一盘生意，"3 月环比 -30%"（春节后自然回落）和"3 月同比 +12%"可以同时成立——口径不说清，结论必然打架。

**快消特别提示**：春节落在 1 月还是 2 月每年不同，会系统性地扭曲 1、2、3 月的同比与环比。遇到年初数据，先确认春节在哪个月，必要时将 1–2 月合并再比较。

## 方法工具箱

| 方法 | 用途 | 操作要点 |
|---|---|---|
| 同比 YoY | 看真实增长 | 至少需要 13 个月数据才有意义 |
| 环比 MoM | 看短期动能 | 结合季节背景解读，别见跌就报警 |
| 移动平均 | 平滑噪声 | 日/周数据用 7 期，月数据用 3 期 |
| 拐点定位 | 找趋势转向 | 关注增速连续同向变化后的反转点 |
| 季节对照 | 区分常态与异常 | 与去年同期、前年同期叠图比较 |
| 增速分档 | 转成业务语言 | 见下表 |

### 增速分档参考（可按企业实际调整阈值）

```
+15% 以上     → 高速增长：找出驱动因素，评估能否持续
+3% ~ +15%    → 稳健增长
-3% ~ +3%     → 基本持平：留意是否跑输市场大盘
-15% ~ -3%    → 下滑：需要关注
-15% 以下     → 快速下滑：优先预警
```

## 参考 SQL（月度同比环比）

```sql
WITH m AS (
  SELECT DATE_TRUNC('month', ship_date) AS mon,
         SUM(amount) AS sales
  FROM shipment
  GROUP BY 1
)
SELECT mon,
       sales,
       LAG(sales, 1)  OVER (ORDER BY mon) AS last_mon,
       LAG(sales, 12) OVER (ORDER BY mon) AS last_year,
       ROUND(100.0 * (sales - LAG(sales, 1)  OVER (ORDER BY mon))
                        / LAG(sales, 1)  OVER (ORDER BY mon), 1) AS mom_pct,
       ROUND(100.0 * (sales - LAG(sales, 12) OVER (ORDER BY mon))
                        / LAG(sales, 12) OVER (ORDER BY mon), 1) AS yoy_pct
FROM m
ORDER BY mon DESC;
```

## 执行步骤

1. 找时间列，确认粒度（单据通常是日，汇总表通常是月）
2. 找指标列：出货额、毛利、回款、箱数等
3. 与用户确认统计口径（出货 or 实销；MoM or YoY；区间范围）
4. 跑基础统计：数据起止、最大最小、均值中位
5. 画走势：实际值 + 移动平均 + 去年同期，三线叠放
6. 标拐点：挑 1–3 个最有业务意义的转折，注明时间与幅度
7. 算同比环比，套用增速分档给出业务判断

## 每个指标的输出格式

- 走向：上行 / 下行 / 横盘 / 宽幅波动
- 幅度：同比、环比各一句，百分比与绝对额同时给（如"同比 -9%，少卖 63 万"）
- 分档：套用上面的分档语言
- 拐点：时间点 + 当时可能关联的经营事件（若可知）
- 置信度：高 / 中 / 低

## 判断纪律

- 不足 3 个时间点：不做趋势结论，注明"样本不足"
- 不做远期外推：最多外推 1–2 期，且必须给出区间而非单点
- 节假日与极端值：标注出来，但不擅自删除
- **量价成对看**：出货额变化时，同步看箱数与单箱均价，判断是"卖多了"还是"卖贵了"
- **出货与实销成对看**：出货涨而实销平，大概率是渠道库存在累积，结论里必须点破

## 经销商场景示例句式

- "二季度出货额逐月减速（4 月 +6%、5 月 +2%、6 月 -4%），6 月为本年首个负增长月"
- "品类甲出货同比 +18%（+120 万），但终端实销同比仅 +3%，渠道库存正在累积"
- "物流费用连续 4 个月环比上行且斜率变陡（+2% → +5% → +9%），建议列入预警"
- "YTD 截至 6 月底出货 2,150 万，按近三月月均推算全年约 4,100 万，距 4,500 万任务差约 9%"
