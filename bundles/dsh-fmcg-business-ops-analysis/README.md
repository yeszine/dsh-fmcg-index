# @dsh-fmcg/business-ops-analysis

Business operations analysis skill for FMCG distributors: trend judgment, structural breakdown, anomaly detection and periodic management reports.

经营分析技能：趋势判断、结构拆解、异常识别，合成周期性经营汇报。

## 包含技能

- `business-ops-analysis`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
