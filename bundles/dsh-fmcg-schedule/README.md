# @dsh-fmcg/schedule

Recurring automation skill: design and operate scheduled reports and checks with cron-style planning.

周期自动化技能：用 cron 式规划落地定时报告与定期检查。

## 包含技能

- `schedule`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
