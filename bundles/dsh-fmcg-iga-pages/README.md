# @dsh-fmcg/iga-pages

Deploy frontend, full-stack and AI agent projects to IGA Pages: Pages Functions, logs, agent and blob SDKs.

IGA Pages 部署技能：前端/全栈/AI agent 项目发布、Pages Functions、日志与存储 SDK。

## 包含技能

- `iga-pages`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
