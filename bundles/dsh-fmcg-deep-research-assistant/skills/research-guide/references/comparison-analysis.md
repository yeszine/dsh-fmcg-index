# 竞品与产品对比分析

## 一、与父技能的关系

完整继承 `research-guide` 的约束：来源分层、硬性约束、检索策略、交叉验证、冲突处理、引用留痕（`[来源:N]` + 文末"信息来源"清单）。本文件只做补充，不做覆盖。

## 二、第一步：目的与深度校准

### 2.1 分析目的 → 输出侧重

| 目的 | 关注维度 | 输出侧重 | 深度 |
| ---- | -------- | -------- | ---- |
| 产品设计参考 | 功能矩阵 + 体验 | 功能缺口清单 + 差异化打法 | 中等 |
| 融资材料 | 市场格局 + 护城河 | 定位图 + 壁垒分析 | 精炼 |
| 战略规划 | 全维度 | SWOT + 五力 + 定价 + 路线图推演 | 深入 |
| 年度复盘 | 份额变动 + 趋势 | 同比变化分析 + 趋势判断 | 中等 |

### 2.2 行业关键指标

采集数据前，先确定该行业里**最能拉开差距的 3–5 个指标**。下表为起点，按实际调整：

| 行业 | 关键指标 |
| ---- | -------- |
| SaaS | ARR、净收入留存率、获客成本回收期、LTV/CAC、Rule of 40 |
| 支付 / 金融科技 | 交易总额、货币化率、渗透率、单笔交易毛利 |
| 平台 /  marketplace | GMV、抽佣率、买卖双边比、复购率 |
| 零售 | 同店销售、库存周转、坪效、线上占比 |
| 工业 | 在手订单、订单出货比、产能利用率、量价拆分 |
| 医药健康 | 处方量、患者数、管线里程碑、研发占收入比 |
| 半导体 | 终端市场收入结构、均价走势、设计中标、产线利用率 |
| 消费软件 | DAU/MAU、留存（次日/7 日/30 日）、ARPU、使用时长 |

> 无明确对应行业时，从竞品财报电话会或官网产品页推导自定义指标，并说明推导依据。

## 三、第二步：信息采集

### 3.1 可信度分级（在父技能分层基础上的本领域口径）

| 等级 | 来源类型 | 处理方式 |
| ---- | -------- | -------- |
| 高 | 官网、定价页、财报、监管申报文件 | 可直接引用 |
| 中 | 一线媒体、分析师研报、用户评价平台 | 标注来源名称 |
| 低 | 传闻、超过 12 个月的旧数据、未核实自媒体 | 打 `[未核实]` |

### 3.2 采集清单

| 维度 | 采集项 | 典型来源 |
| ---- | ------ | -------- |
| 基本面 | 成立时间、融资阶段、团队规模、用户量 | 官网、创投数据库 |
| 产品 | 核心功能、近期发布、公开路线图 | 官网、更新日志、官方博客 |
| 定价 | 档位、价格点、免费额度、计费模式 | 定价页 |
| 口碑 | 高频好评点、高频吐槽点、评分 | 评价平台、应用商店、社区 |
| 战略 | 目标客群、获客渠道、合作动态、定位表述 | 媒体报道、官方社媒、招聘信息 |
| 财务（如已上市） | 收入、毛利、分部结构、资本配置 | 监管申报、财报电话会纪要 |

### 3.3 时效标注

每条竞品数据都必须带时间标签（如"截至 2026 年第一季度公开信息"）。数据超过 6 个月时，提醒用户复核最新情况。

### 3.4 并行与顺序

- 多家相互独立的竞品 → 并行铺开，一家一条检索线；
- 单一对手深挖 → 顺序钻取；
- 市场快速变化 → 时效优先，先看近期二手内容再回溯一手出处。

## 四、第三步：分析框架

### 4.1 波特五力

| 力量 | 分析视角 | 评估要点 |
| ---- | -------- | -------- |
| 供方议价力 | 上游依赖 | 关键技术 / 人才 / 资源的集中度、切换成本 |
| 买方议价力 | 下游话语权 | 客户集中度、转换成本、价格敏感度 |
| 新进入者威胁 | 进入壁垒 | 技术门槛、资本要求、品牌壁垒、网络效应、监管门槛 |
| 替代品威胁 | 替代方案 | 现有替代品、替代性价比 |
| 现有竞争强度 | 玩家博弈 | 竞争者数量、集中度、差异化程度、退出壁垒 |

每种力量给出 强 / 中 / 弱 评级 + 一句带引用的理由；最后汇总行业吸引力：高 / 中 / 低。

### 4.2 护城河评估

| 护城河类型 | 评估标准 |
| ---------- | -------- |
| 网络效应 | 用户 / 供给侧飞轮强度 |
| 转换成本 | 集成深度、数据锁定、工作流依赖 |
| 规模经济 | 规模化后的单位成本优势 |
| 无形资产 | 品牌、专有数据、牌照、专利 |

逐项评级（强 / 中 / 弱）并附证据，每条论断都要有来源。

## 五、第四步：多维对比

### 5.1 功能对比矩阵（核心交付物）

| 功能模块 | 子功能 | 我方 | 竞品 A | 竞品 B | 竞品 C |
| -------- | ------ | ---- | ------ | ------ | ------ |
| {模块 1} | {子功能 1} | ✅ 完整 | ✅ 完整 | ⚠️ 基础 | ❌ 无 |
| | {子功能 2} | ⚠️ 基础 | ✅ 完整 | ✅ 完整 | 🔜 规划中 |

图例：✅ 完整支持 — ⚠️ 有但不完整 — ❌ 没有 — 🔜 官方已预告。

### 5.2 SWOT（逐竞品，或"我方 vs 行业"）

| | 正面 | 负面 |
| - | ---- | ---- |
| **内部** | 优势 | 劣势 |
| **外部** | 机会 | 威胁 |

每象限 2–3 条，每条必须挂靠可验证的事实，禁止空话（如"团队强""技术先进"）。

战略规划场景追加 **SWOT 交叉策略**：SO（借势发挥）、WO（补短抓机）、ST（以长御敌）、WT（紧急防御）。

### 5.3 财务基准对比（维度含财务时）

统一币种、统一财年口径，列出收入、增速、毛利率、EBITDA 利润率、自由现金流利润率等；上市公司可加估值对比（P/E、EV/EBITDA、EV/Revenue、相对中位数的溢价 / 折价）。

### 5.4 定价策略对比（维度含定价时）

对比免费档能力、入门价、企业版价、计费模式（按席位 / 按用量 / 按功能），并归类定价策略类型：

- **渗透型**：低价抢份额（免费档很慷慨是信号）；
- **撇脂型**：高价高端定位（功能强锁在高档）；
- **免费增值型**：核心免费、进阶付费（看免费与付费的功能落差）。

### 5.5 体验与技术架构（可选维度）

- 体验：核心流程步数、学习成本、任务完成效率（对比关键操作的点击数与耗时）；
- 架构：架构模式、技术栈、性能指标、开放程度（API 广度、集成能力、可扩展性）。

## 六、第五步：定位与策略推演

### 6.1 定位图

选出**区分度最高的两个维度**（如"功能深度 × 易用性"或"价格 × 功能广度"），把所有产品放进四象限，逐象限给出特征描述与代表产品。

### 6.2 市场格局分类

| 格局 | 特征 | 策略含义 |
| ---- | ---- | -------- |
| 一大多小 | 头部份额 >50% | 避开正面，做细分差异 |
| 双寡头 | 前二合计 >70% | 绑定生态或做第三选择 |
| 分散 | 前五各占 <20% | 抢先占住一个细分 |
| 萌芽 | 无明显领先者 | 投入市场教育、尽早建品牌 |

### 6.3 策略推演

从竞品近 3–6 个月的公开信号（产品更新、融资、招聘、合作公告）推断其下一步：

1. **信号收集**：分竞品列出近期关键动作；
2. **模式识别**：某领域密集发版 → 可能在加码；某职能大量招聘 → 可能在铺新产品线；降价或免费档扩容 → 可能在抢份额；
3. **推演表**：

| 竞品 | 近期关键动作 | 推断战略意图 | 对我方影响 | 置信度 | 建议应对 |
| ---- | ------------ | ------------ | ---------- | ------ | -------- |

- **已确认事实**与**推断意图**必须分栏呈现，推断项必带置信度（高 / 中 / 低）；
- 数据支持时给出短期（1–3 个月）与中期（3–12 个月）两档推演。

### 6.4 情景分析（有投资语境时）

牛市 / 基准 / 熊市三情景，概率合计约 100%，每个驱动因素都带来源。

## 七、第六步：差异化打法

| 层级 | 含义 | 动作项 |
| ---- | ---- | ------ |
| 补齐 | 竞品都有、我方没有的功能 | 列功能 + 优先级 + 工作量估计 |
| 强化 | 我方领先或独有的功能 | 列待强化优势 + 对外传播话术 |
| 开创 | 所有竞品都未覆盖的空白 | 列探索方向 + 验证方法 |

附监控节奏建议：周度跟踪发版与社媒、月度刷新功能矩阵、季度出完整竞品简报、重大事件（融资 / 并购 / 高管变动）触发即时影响评估。

## 八、输出规范

### 8.1 默认结构

1. 摘要——一页结论：格局类型、我方位置、Top 3 行动项；
2. 范围与方法——覆盖的竞品、分析的维度、数据截止日、可信度概况；
3. 行业背景——五力 + 护城河；
4. 多维对比——功能矩阵、SWOT、财务基准、定价对比（按所选维度）；
5. 竞争定位——定位图 + 格局分类；
6. 策略推演——逐竞品推演表；
7. 差异化打法——三层策略 + 监控节奏；
8. 附录——原始数据表、方法说明。

> 第 3–6 节按分析目的伸缩：融资材料压缩为一页"定位 + 壁垒"，战略规划则全部展开。

### 8.2 格式

- 默认 Markdown；用户要求时可改为其他文档格式。
- 标题客观中立，不反问、不煽动。
- 图表遵循父技能第四节。

## 九、质量门槛（交付前逐项自检）

- [ ] 每个量化数值都带来源标注。
- [ ] 所有竞品在**相同维度、相同刻度**下评估，无口径错配。
- [ ] SWOT 条目均有事实支撑，无空泛褒贬。
- [ ] 每个竞品章节都有数据时效标注。
- [ ] 可信度分级已落实，`[未核实]` 标签该打的都打了。
- [ ] 推演表中事实与推断分列，推断带置信度。
- [ ] 情景概率合计约 100%（如适用）。
- [ ] 行业关键指标已进入对比表。
- [ ] 缺失数据标 `N/A` 或 `—`，未编造。
- [ ] 五力各评级均附证据。

## 十、红线

1. 禁止编造竞品数据；未核实信息打 `[未核实]`。
2. 评估保持客观，禁止贬损性措辞。
3. 时效标注是强制的；数据超过 6 个月须提示复核。
4. 推断意图必带置信度标签。
5. 跨对象比较统一指标定义、统一会计期间、统一币种。
