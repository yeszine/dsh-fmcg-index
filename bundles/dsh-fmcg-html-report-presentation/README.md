# @dsh-fmcg/html-report-presentation

Skills for self-contained HTML deliverables: visually designed reports/dashboards and animation-rich slide decks.

自包含 HTML 交付物技能：视觉化报告/仪表盘与动画演示文稿。

## 包含技能

- `html-report`
- `html-deck`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
