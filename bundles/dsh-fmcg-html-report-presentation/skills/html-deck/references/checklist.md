# 交付前检查清单（html-deck）

逐项确认，全部通过后才能交付。

## A. 路由正确性

- [ ] 用户没有明确要求 PPT/pptx 文件（若有 → 应转办公文档技能，本技能不交付）

## B. 自包含性

- [ ] 交付物是**单一 `.html` 文件**，双击即可放映
- [ ] 无本地相对路径 / `file:///` 引用；无网络字体
- [ ] 依赖为零或仅公共 CDN；断网时文字内容完整、图表页有静态降级
- [ ] base64 图片单张 < 150KB，整文件 < 2MB

## C. 结构与叙事

- [ ] 有封面 + 目录 + 结尾，正文 ≥ 6 页时有章节分隔页
- [ ] 封面/结尾极简：封面无数据卡片，结尾无功能列表
- [ ] 一页一个核心信息；只看标题能串出完整故事
- [ ] 每个 `.slide` 有 `data-label`；讲者提示全部在 `.notes`，不上屏
- [ ] 单页正文字号 ≥ 28px；表格 ≤ 6 列 ≤ 8 行

## D. 视觉与动画

- [ ] 全部颜色走 CSS 变量；正文对底色对比度 ≥ 4.5:1
- [ ] 全套只有 1 个主强调色；图表配色来自 CSS 变量而非库默认色板
- [ ] 每页动画 ≤ 2 种，时长 0.4–0.9s；含 `prefers-reduced-motion` 降级
- [ ] 全屏图片页加了暗色遮罩，文字可读
- [ ] 无紫渐变白底、无同质卡片网格堆砌

## E. 放映功能

- [ ] `→` / `空格` / `Enter` 下一页，`←` 上一页可用
- [ ] `F` / `F11` 全屏切换可用
- [ ] 画布 1920×1080，窗口任意尺寸下等比缩放、不变形、不溢出
- [ ] 图表随窗口缩放正常 resize（SVG 渲染模式）
- [ ] 未覆盖翻页机制依赖的 `.slide` 显隐样式（未乱加 `position`/`display`/`opacity` 覆盖）

## F. 交付说明

- [ ] 已告知文件绝对路径、入口文件名、键盘操作与全屏建议
- [ ] 若用了 CDN，已说明断网降级行为
- [ ] 未私自起服务器或替用户打开浏览器
