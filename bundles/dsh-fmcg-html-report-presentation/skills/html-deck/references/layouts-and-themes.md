# 版式 · 动画 · 主题速查（html-deck 配套）

## 1. 版式目录（按页面角色选用）

| 页面角色 | 推荐版式 | 要点 |
|---|---|---|
| 封面 | `cover` | 居中大字标题 + 副标语；不放数据卡片 |
| 目录 | `toc` | 编号列表 3–6 项，当前章节可高亮 |
| 章节分隔 | `section` | 超大编号 + 一句话章节引子 |
| 要点罗列 | `bullets` / `two-col` / `three-col` | 每点一行主句 + 一行补充，≤ 6 点 |
| 大数字/KPI | `stat` / `kpi-grid` | 数字 ≥ 96px 等宽字体，配 12–16px 标签 |
| 数据图表 | `chart-bar` / `chart-line` / `chart-pie` / `chart-radar` | 图占页宽 60–70%，旁侧留白给结论句 |
| 表格 | `table` | ≤ 6 列 ≤ 8 行，超出则拆页 |
| 流程/架构 | `flow` / `arch` | 内联 SVG 连线，层级 ≤ 3 |
| 时间线 | `timeline-h` / `timeline-v` | 节点 ≤ 7 个 |
| 对比 | `compare` / `pros-cons` | 双栏对称，栏首各一句结论 |
| 引言 | `quote` | 超大引号 + 居中文本 + 署名 |
| 图片 | `img-full` / `img-split` / `img-grid` | 全屏图需加暗色遮罩保证文字可读 |
| 行动号召 | `cta` | 一句主张 + 一个行动入口 |
| 结尾 | `thanks` | 只放收束语，不堆内容 |

组合规则：每页只用一种主版式；一页放不下就拆页，不缩字号硬塞。

## 2. 动画名录（CSS 实现，`data-anim` 驱动）

| 类别 | 名称 | 适用 |
|---|---|---|
| 方向淡入 | `fade-up` `fade-down` `fade-left` `fade-right` | 正文页默认，安全 |
| 入场强调 | `rise-in` `zoom-in` `blur-in` | 封面、章节页 |
| 列表 | `stagger`（子元素依次延迟 80ms） | bullets、toc |
| 数字 | `count-up` | KPI 大数字 |
| 文字 | `typewriter` `shimmer` | 引言页少量点缀 |
| 图形 | `draw-line`（SVG 描边动画） | 流程图、时间线 |

使用约束：
- 每页 ≤ 2 种动画；全套幻灯片以 `fade-up` 为主基调。
- 动画时长 0.4–0.9s，`ease` 或 `cubic-bezier(.2,.7,.3,1)`；不用弹跳曲线。
- 只做出场动画，不做循环跑马灯类干扰动画。
- 提供降级：`@media (prefers-reduced-motion:reduce){ [data-anim]{animation:none} }`。

## 3. 主题令牌速查

所有主题共享同一组变量，换主题 = 换一组变量值：

| 变量 | 语义 |
|---|---|
| `--bg` | 页面底色 |
| `--surface` | 卡片/色块 |
| `--ink` | 主文字 |
| `--muted` | 次要文字 |
| `--accent` | 主强调（图表主色、关键词） |
| `--accent2` | 次强调（对比系列、点缀） |

常用主题方向（自行定色值，以下是气质描述而非固定配方）：

| 主题方向 | 受众 | 气质 |
|---|---|---|
| 深空墨蓝 | 技术/ infra | 近黑蓝底 + 青/琥珀强调，等宽数字 |
| 极简白 | 管理层/咨询 | 白底 + 藏青强调 + 大量留白 |
| 编辑衬线 | 品牌/设计 | 米白底 + 衬线大标题 + 单强调色 |
| 暗夜霓虹 | 发布/路演 | 深底 + 高饱和强调 + 大图全屏 |
| 暖调马卡龙 | 消费/教育 | 浅暖底 + 柔和多彩强调 |
| 学术纸感 | 答辩/培训 | 纸白底 + 学者蓝绿 + 细分隔线 |

约束：正文对底色对比度 ≥ 4.5:1；全套只有 1 个主强调色；避免"紫渐变白底 + 同质卡片"的通用 AI 模板感。
