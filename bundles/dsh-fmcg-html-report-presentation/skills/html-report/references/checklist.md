# 交付前检查清单（html-report）

逐项确认，全部通过后才能交付。任何一项不通过，先修复再复查。

## A. 自包含性

- [ ] 交付物是**单一 `.html` 文件**，双击可在浏览器直接打开
- [ ] 无本地相对路径引用（无 `./assets/`、`file:///`、绝对盘符路径）
- [ ] 外部依赖为零，或仅公共 CDN；断网时正文与表格仍完整可读
- [ ] base64 图片单张 < 150KB，整文件体积 < 1MB（纯数据长页可放宽至 2MB）
- [ ] 无网络字体、无字体文件嵌入

## B. 设计一致性

- [ ] 所有颜色、字号、圆角均通过 CSS 变量引用，无散落硬编码色值
- [ ] 正文/背景对比度 ≥ 4.5:1
- [ ] 全页只有 1 个主强调色；图表配色来自 `getComputedStyle` 读取的变量，非库默认色板
- [ ] 重点强调方式全文统一（`<strong>` 或 `<mark class="key">` 二选一，未混用）
- [ ] 语言与用户输入语言全文一致

## C. 内容与图表

- [ ] 每个图表/插图都有可见标题（figcaption 或前置小标题）
- [ ] 图表在窗口缩放时正常 resize
- [ ] 热力图/多分类图无空轴分类（轴上不声明无数据的类目）
- [ ] 引用编号连续（[1]…[N]），每条上标在页脚来源区有对应 `id="cite-N"` 条目
- [ ] 来源 URL 是可点击链接且不会溢出页宽

## D. 响应式与打印

- [ ] ≤768px 视口下：多列网格全部坍缩单列、无横向滚动条（表格除外）
- [ ] 所有表格包在 `overflow:auto` 容器中；4 列以上表格未被塞进多列布局
- [ ] 正文字号 ≥ 14px，注释 ≥ 12px
- [ ] `@media print` 生效：隐藏交互控件、章节分页正确、图表不截断

## E. 交付说明

- [ ] 已告知用户文件的绝对路径与打开方式
- [ ] 若使用了 CDN，已说明断网降级行为
- [ ] 未私自启动本地服务器或替用户打开浏览器预览
