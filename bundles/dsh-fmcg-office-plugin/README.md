# @dsh-fmcg/office-plugin

Office document skills: Excel read/write with formulas and charts, Word documents, PDF extract/merge, PowerPoint decks.

办公文档技能集：Excel 读写/公式/图表、Word 文档、PDF 提取合并、PPT 演示文稿。

## 包含技能

- `xlsx`
- `docx`
- `pdf`
- `pptx`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
