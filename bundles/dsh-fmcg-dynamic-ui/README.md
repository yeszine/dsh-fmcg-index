# @dsh-fmcg/dynamic-ui

Inline visual responses skill: render diagrams, charts, comparisons and small interactive demos next to text answers.

内联可视化技能：在文字回答旁展示示意图、图表、对比与小型交互 demo 的通用规范。

## 包含技能

- `dynamic-ui`

## 安装

通过 DSH「插件 → 发现」添加索引源 <https://yeszine.github.io/dsh-fmcg-index/index.json> 后一键安装；
或手动将该仓库作为 bundle 加入 DSH profile。
